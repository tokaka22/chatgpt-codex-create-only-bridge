# Validation scope

The first source release is based on a macOS reference deployment verified in October 2026. This file contains only aggregate results; private source material, original jobs, credentials and machine paths are not distributed.

## Automated checks shipped with this repository

- Publisher: 22 checks of exclusive creation, repeated fresh versions, traversal/link/alias rejection, source hashes and snapshot changes, byte/UTF-8 limits, partial receipts, and a real isolated stdio subprocess.
- Runtime guard: 36 checks of effective configuration, read-only confirmation, old-thread/config/tool denial, active turn ownership and the required routing host.
- Protocol adapter: 26 checks of modern/legacy protocols, schemas and metadata, Host/Origin/auth admission, request bounds, unsupported semantics, batch rejection and observer disconnect/timeout independence.
- Configuration generator: private fresh output, fixed version/policy boundaries, helper hashes, and refusal to adopt existing or symlink destinations.

These checks make no LLM requests. CI runs the same tests on Linux and macOS; native sandbox/model/tunnel behavior is outside these mocked tests.

## Historical live integration

The reference operator separately observed two actual ChatGPT web publications of the complete nine-chapter, 47-subsection text and HTML document. The web supplied a different newly authored README each time; complete existing source bodies were copied by exact hash rather than regenerated. Both jobs completed with zero interaction requests, separate UUID directories and matching post-publication hashes. Previous files were unchanged.

The final publication used the official SDK v2 adapter. It verified 115 HTML internal links with no broken targets or duplicate IDs, then ran one 70-second wait. The operator restarted only the independent tunnel during that job; core and adapter process IDs stayed unchanged and the same job later completed. The adapter's unit tests also simulate observer cancellation and SSE timeouts independently of backend work.

The original HTML's desktop/mobile layout had been checked in a browser; new copies had the same bytes. This is not a claim that every new publication received an independent visual review. There was no whole-machine reboot, lid-close or physical network-loss acceptance test.
